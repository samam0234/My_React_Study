# JSX 미니 게시판

`JSX_study/demo`에서 익힌 기초를 한 화면에 모아 둔 가벼운 응용 실습입니다. JavaScript + JSX만 사용합니다.

TSX 종합 프로젝트(`TSX_study/project`)보다 범위가 짧습니다. 페이지네이션, 즐겨찾기, 댓글, 보호된 마이페이지는 넣지 않았습니다.

## 포함된 것

- 게시글 목록 10개와 제목 검색
- 목록에서 상세로 이동
- 이메일/비밀번호 검증이 있는 로그인
- Context로 헤더에 로그인 상태 표시

## 실행

```bash
cd JSX_study/project
npm install
npm run dev
```
